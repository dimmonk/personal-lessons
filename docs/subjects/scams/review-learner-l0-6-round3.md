## The way of deciding, in my own words (before the first practice question)
- l1: Read the message, find the one line that asks me to do something, and name the thing it asks for: money, a sign-in or code, my details, my phone or computer, or nothing. How it looks proves nothing.
- l2: Anything that comes with the message (link, number, reply, badge, "I'll transfer you", caller ID) belongs to the sender. I check only through something I had before the message: the app, the number on my card or bill, an address I type, a number I saved.
- l3: Three questions. What does it want? Did I start it? If not, do I deal with them or know the person? Started: do it. Not started but I deal with them: check my own way. Neither: leave it.
- l4: A pop-up that says call a number is never real. Calling the number it gave is not starting it myself. Open a file or install an app only if I asked for it.
- l5: A code is typed by me on a page I opened, never read out. An Approve or code I did not trigger means someone is trying my account: deny, then change the password in the app. Allow a permission only if it answers what I just tapped.
- l6: Someone I know only online is not someone I know. Real prizes, loans and jobs cost nothing up front. Nobody honest charges to get money back. A known person asking for money I had not agreed: call their saved number.

I could state each in my own words. No defect there.

## Defects (decide the verdict)
D1 (l3 Check Q25, Eli call). Two of the three "How do you check?" options are the same action: "Calling back the number my phone shows for the call" and "Call back the number my phone shows for the call", with different feedback. A beginner sees two identical options. Fix: replace one with a different wrong choice (e.g. "Call the number he gave me on this call" or "The number I find by searching").

D2 (l3 Check Q22, l4 Item 7). The message says "As you asked, we tried to deliver again" / "As you asked, here is how to follow your delayed mug", but the scenario never says whether I asked. Rule 2 says do it if I started it, so I stalled: did I? Fix: add to rule 2 "A message that says you asked is the sender's claim; only what you remember doing counts", and state "You have asked for nothing" in these premises.

D3 (l3 Check Q16, also l0 Q-style callbacks). I asked for a call back in the app; a caller then asks my date of birth. Rule 2 says a callback is fine "on a number I already had", but the incoming number is not stated to be one I had, and l2 taught that shown numbers can be faked. Both Do and Check are defensible. Fix: state the call comes from the number saved in the app, or teach what makes an expected callback safe (I asked, and it asks only what the call needs).

D5 (l6 Item 4, Harbor Café raffle). The text arrives unrequested and says "Reply with your name". Rule 2 gives no case where an unrequested prize text is something I started. How does the café have my number is not stated. Check first is also defensible. Fix: say the ticket form asked for my number for the draw and that the café is a place I deal with, or make the checked answer right.

D6 (l3 Item 15 and Check Q27, l6 Item 1, Item 11, Check Q14). The "What else do you do?" list is always the same four options with the right one ("Tell someone I know in person") always last. Passable by position. Fix: shuffle the order each time.

D4 (l4 Item 15, Check Q24, l0 Q9, l5 Item 15/Q24, l6 chat sims). In every call and chat simulation the right reply is the one that says hang up / stop replying / send nothing, so a learner can pass them without reasoning. The slip count does not prevent that. Fix: include one simulated call or chat where the right reply is to go along (an expected real callback).
